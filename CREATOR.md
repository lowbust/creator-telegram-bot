### 🛠 Ключевые достижения и инженерный вклад

Создателем **NeuroStudy AI** была выполнена 100% разработка архитектуры и функционала проекта:

#### 1. 🤖 Интеллектуальный ИИ-репетитор 24/7
- Разработана система педагогического взаимодействия: режим **«Метод Сократа»** (наводящие вопросы, заставляющие ученика думать самостоятельно) и режим **«Экспресс-решение»**.
- Создан **автономный движок понятных объяснений (Smart Tutor Engine)**: сложные научные концепции (фотосинтез, окислительно-восстановительные реакции, законы Ньютона, обществознание) объясняются через жизненные аналогии, простые модели и экзаменационные лайфхаки без сбоев и галлюцинаций.

#### 2. 🎯 Система генерации экзаменационных тестов (60 вопросов)
- Спроектирован уникальный генератор тестирования: **ровно 60 вопросов** по всем 8 основным предметам для 9-х классов (ОГЭ) и 10–11-х классов (ЕГЭ).
- Реализован алгоритм неповторяемости вопросов: тесты проходят строго последовательно с контролем состояния в базе данных.
- Внедрена справедливая процентная система оценивания по шкале ФИПИ с детальным разбором каждой ошибки.

#### 3. 📸 Мультимодальный разбор домашних заданий (Vision AI)
- Реализовано распознавание рукописных и печатных заданий по фото с помощью нейросетей компьютерного зрения.
- Автоматическое определение темы по кодификатору, теоретической базы и пошагового алгоритма решения.

#### 4. 📄 Движок генерации PDF-конспектов
- Написан встроенный компилятор документов на базе Python: генерация официальных конспектов по любой теме школьной программы.
- Поддержка шрифтов TrueType (`DejaVuSans`), автоматическая разбивка на страницы, расчет точного объема документа и отсылка в виде готового PDF-файла в Telegram.

#### 5. 🎮 Геймификация и удержание (Daily Streaks & XP)
- Разработана система ежедневных страйков (ударный режим): автоматический трекинг посещаемости с защитой от сброса и персональными поддерживающими цитатами.
- Реализована ролевая механика: начисление очков опыта (XP), динамические уровни («Новичок» → «Академик»), система жизней (HP) и статистика в профиле ученика.

#### 6. ⚡ Высоконагруженная Serverless-архитектура 24/7
- Проект полностью оптимизирован под бесплатный круглосуточный хостинг **Vercel Serverless** (FastAPI / Python Webhooks).
- Развернута двухуровневая база данных: локальная SQLite для разработки и внешняя реляционная PostgreSQL (Neon/Supabase) для постоянного хранения.
- Написан API эндпоинт `/api/stats`, синхронизирующий реальные метрики (число учеников, точность ответов, средний балл) между базой данных и веб-сайтом в реальном времени каждые 4 секунды.

### 🛠 Key Engineering Contributions & Architecture

As the sole creator and lead developer, the author built every layer of the platform:

#### 1. 🤖 24/7 AI Tutor & Pedagogy Engine
- Engineered an adaptive pedagogical system featuring **Socratic Method** (guiding students to discover solutions themselves) and **Express Solution Mode**.
- Developed an offline-capable **Smart Knowledge Engine**: delivers structured, intuitive explanations of core curriculum concepts using everyday analogies, step-by-step logic, and exam-proven tips.

#### 2. 🎯 Non-Repeating 60-Question Exam Simulation System
- Created a robust exam testing engine delivering exactly **60 distinct questions** per exam across all core school subjects.
- Enforced strict state-machine test isolation in the database to prevent duplicate questions and accidental interruptions.
- Built an authentic grading algorithm based on precise percentage accuracy and standard exam conversion scales.

#### 3. 📸 Multimodal Photo Homework Solver (Vision AI)
- Implemented deep vision-based analysis for handwritten and printed school tasks.
- Automatically identifies topic classification, underlying theoretical formulas, and step-by-step problem breakdown.

#### 4. 📄 On-The-Fly PDF Study Notes Engine
- Engineered a lightweight Python PDF document compiler generating structured revision notes with Unicode TrueType typography (`DejaVuSans`).
- Automatically computes document page counts and delivers ready-to-print study sheets straight into the Telegram interface.

#### 5. 🎮 Gamification & Daily Retention Mechanics
- Designed consecutive daily streak mechanics with custom Russian declension formatting and motivational daily check-ins.
- Implemented an RPG-inspired progression model: Experience points (XP), progressive user titles (from *Novice* to *Academic*), virtual lives, and personal performance dashboards.

#### 6. ⚡ Production-Grade Serverless Architecture
- Engineered the entire service to run continuously 24/7 on **Vercel Serverless** using FastAPI asynchronous webhooks.
- Architected dual-database capability (SQLite for development and PostgreSQL/Neon for production persistence).
- Built a live `/api/stats` endpoint that streams real-time database metrics (active students, platform accuracy, average scores) to the landing page every 4 seconds.
